# Maycrest Command 🦥

> Strategic orchestration and fast routing — the front door to the Sloth Skill Tree.

<!-- AUTOGEN:counts:start -->
**2 skills · 4 commands**
<!-- AUTOGEN:counts:end -->

Use `/sloth` for full strategic decomposition, or `/sloth-dispatch` to route a single
task to the right specialist without ceremony.

## Skills

<!-- AUTOGEN:skills:start -->
| Skill | Triggers |
|-------|----------|
| `sloth-command` | Use when a task needs decomposing and dispatching to Maycrest specialists — multi-pillar, ambiguous, or high-stakes work that warrants a strategic execution plan before delegation. |
| `sloth-dispatch` | Use when a clear, single-owner task needs routing to the right Maycrest specialist fast, without the full strategic assessment of Sloth Command. |

**Commands:** `/sloth`, `/sloth-dispatch`, `/sloth-status`, `/sloth-update`
<!-- AUTOGEN:skills:end -->
