## Skills

<!-- AUTOGEN:skills:start -->
| Skill | Triggers |
|-------|----------|
| `cloud-security-architect` | Use when assessing cloud security posture across AWS, Azure, or GCP — reviewing IAM policies, running CIS benchmark checks, auditing network or storage exposure, or hardening infrastructure-as-code. |
| `compliance-auditor` | Use when assessing readiness for SOC 2, GDPR, HIPAA, PCI-DSS, or ISO 27001, running a gap assessment, building evidence collection, or preparing for an external audit or breach notification. |
| `forensics-investigator` | Use when investigating a breach after the fact — collecting forensic evidence, analyzing memory, disk, or log artifacts, reconstructing an attack timeline, or preserving chain of custody. |
| `incident-response-commander` | Use when managing a production incident or outage, writing a post-mortem, setting up on-call rotations and escalation policies, defining SLOs and error budgets, or building incident runbooks. |
| `legal-compliance` | Use when reviewing GDPR, SOC2, or privacy posture for Maycrest products and client data — handling data subject or erasure requests, or reviewing a privacy policy or data processing agreement. |
| `offensive-security-engineer` | Use when running a penetration test or red team engagement, proving a vulnerability is exploitable, emulating an adversary, or chaining findings into an attack path with a working proof of concept. |
| `secure-lead` | Use when a security or engineering task needs routing to the right specialist — backend, frontend, DevOps, AI, threat detection, offensive security, forensics, or compliance. |
| `security-engineer` | Use when auditing a Supabase or Expo app for vulnerabilities — reviewing RLS policies, hardening auth or an Edge Function, securing Stripe webhooks, or threat modeling against OWASP risks. |
| `threat-detection-engineer` | Use when writing SIEM or Sigma detection rules, mapping or assessing MITRE ATT&CK coverage, tuning alert noise, hunting for threats, or building a detection-as-code pipeline. |
| `threat-intel-analyst` | Use when profiling a threat actor, assessing a threat landscape, producing a CTI report, managing IOCs, or mapping campaigns to MITRE ATT&CK. |
